# 3-minute demo script

Before recording: `npm run build && npm start`, open http://localhost:8787 on a phone-sized window, and run one KYC upload once so the OCR language file is downloaded.

| Time | Screen | Do | Say |
|---|---|---|---|
| 0:00-0:15 | Partner console | Show the KPI tiles and funnel | "Today only 7.4% of SMB leads activate. It takes 17.6 days, 3 chasing calls and ₹15,000 to acquire each one. 61% of drops are things a digital journey removes." |
| 0:15-0:55 | Advisor | Type "I run an electronics shop in Visakhapatnam with 6 staff", tap **1**, paste `37NBLXS1145E1ZU`, tap **UPI / card billing**, **CCTV cameras**, **Done**, **Business broadband, ₹3,000** | "Sahayak asks a few questions. When I paste my GSTIN it fills in my business from the GST registry. The bundle is built by a rules engine from what similar businesses bought, so it is always valid." |
| 0:55-1:00 | Advisor | Switch language to Hindi (optional) | "It works in Hindi, and in 10 languages with the Claude engine." |
| 1:00-1:25 | Quote | Toggle **Secure Wi-Fi** on, switch to **24 months** | "One monthly price, GST shown, live re-pricing. Add-ons start switched off because price is the top reason people drop." |
| 1:25-2:10 | Smart KYC | Accept consent, choose specimen **K12**, **Verify** → all green. Then choose **K07**, **Verify** | "Consent comes before any upload, and photos are never stored. OCR reads each document, then 15 checks run against the GST and Udyam registries. K07's certificate shows a different legal name than the registry - an altered document, caught in seconds." |
| 2:10-2:35 | KYC → Tracker | Back to **K12**, verify, **Sign with Aadhaar OTP**, enter the OTP, then **Demo: next day** twice | "Signed by OTP. The tracker shows every service and sends proactive updates, so there's no reason to call. Live in 5 days instead of 17.6." |
| 2:35-3:00 | Partner console | Scroll to win-back list and **Advisor sessions** | "Partners see which dropped leads to call first - our model ranks them, top 20% activate at twice the base rate - and every chat that didn't close, so digital feeds the field force instead of competing with it." |
